# 005 股票页面：先看数据，再让 agent 分析

**决定**：新增 `/stock` 页面。上半部分是行情接口直接给的数据（走势图、关键数字），下半部分是 agent 的分析卡片。

## 为什么把两者放在一页

- 打开就能看懂：图表和数字不需要读长段文字
- 能直接对照：agent 卡片里的「依据」数字，和上面图表、数字块是同一份数据，看的人可以自己核对 agent 有没有说错
- 省钱：图表数据走 `/api/series`，不经过模型；只有点「让 agent 分析」才调用模型

## 和大盘对比

新增工具 `compare_with_index`：A 股比沪深300，港股比恒生指数，澳股比 ASX 200，韩股比 KOSPI，日股比日经225，其他比标普500。返回同期涨跌、超额收益（股票减大盘）和每日涨跌的相关系数。

图表上「和大盘对比」时，两条线都换算成「起点 = 100」，共用一个纵轴。没有用两个纵轴（左边股价、右边指数点数），因为双纵轴的两条线可以靠调刻度画成任意的「交叉」，很容易误导。

两个市场休市日不同（比如 A 股国庆休市、美股照常），对比时只用两边都开盘的日子。

## 没有做的

- 市盈率、市值等基本面数据：Yahoo 的这类接口需要登录态，经常失效；以后换一个稳定的数据源再加
- K 线图：对学习「agent 怎么用数据」帮助不大，折线足够

## 怎么验证

- `tests/test_api.py`：`/api/series` 返回价格点、关键数字和对应的大盘；空代码返回 404；静态文件路由不能读到 `static` 目录以外的文件
- `tests/test_agent.py`：股票分析问题会调用 `compare_with_index`，并且依据里引用了它
- 评测新增 `stock-vs-index` 和 `rate-similar-history` 两题
