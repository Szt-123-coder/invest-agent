# 001 Agent 核心循环：用 LangChain，另配手写版

**决定**：正式运行用 LangChain 的 `create_agent`（底层是 LangGraph），另外写一个 30 行左右的手写版 `app/react_by_hand.py` 只用于学习。

## 为什么需要一个循环

agent 和普通聊天机器人的区别在于：它自己决定要不要调用工具、调哪个、调几次。这个模式叫 ReAct（Reasoning + Acting）：

1. 把问题和工具列表发给模型
2. 模型回答「我要调 get_quote，参数是 AUD/CNY」
3. 程序执行工具，把结果交回模型
4. 模型决定继续调工具，还是给出最终回答

## 考虑过的方案

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| 只手写 | 每一行都看得懂 | 流式输出、出错处理、状态管理都要自己做 |
| 只用 LangChain | 现成功能多，招聘要求常见 | 框架层次多，出问题时新手难看懂 |
| **LangChain + 手写版对照**（选这个） | 两种都会，能讲清框架底下做了什么 | 多维护一个小文件 |

## 怎么验证

- `tests/test_agent.py` 检查一个多步问题依次调用了 3 个工具，并且每一步都存进了数据库
- `python -m app.react_by_hand "澳元最近怎么样"` 可以看到手写版每一步打印出的工具调用
