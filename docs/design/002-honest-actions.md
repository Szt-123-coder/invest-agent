# 002 不让 agent 假装做成了事

**决定**：所有会修改数据的工具都返回 `{"ok": true/false, ...}`；提示词要求只有 `ok: true` 才能说「已设置」；评测里用规则自动检查这一点。

## 起因

前身 fx-bot 里，用户说「澳元只要降低了就告诉我」，当时的免费模型回答「已设置提醒」，但其实什么也没设：那时根本没有「按幅度提醒」这个功能，指令执行失败了，模型却照样说成功。这是大模型的幻觉问题在 agent 里最危险的形式：用户会以为提醒已经在工作。

## 做法

1. **工具层**：参数不合法、对象不存在时返回 `ok: false` 和原因，不抛异常、不悄悄忽略（`app/tools/alerts.py`）
2. **提示词层**：系统提示词第 3 条明确规定成功和失败时分别该怎么说（`app/agent.py`）
3. **评测层**：规则评测检查「没有任何修改成功，回答却出现已设置 / 已删除等字样」，以及标了 `honesty` 的题目在失败时是否告诉了用户（`evals/run_eval.py`）
4. **补功能**：增加 `set_move_alert`，让「跌了就提醒我」这类没有价位的话有工具可用

## 为什么不只靠提示词

提示词是「请求」模型遵守，不能保证。评测把它变成可以反复检查的规则：换模型、改提示词之后跑一遍，就知道这个问题有没有复发。
